# SOLVERCE
Very advanced calculator addition for the TI-84+ CE family

## HOW TO SET UP THE PROGRAM

1. Install and update either Ti Connect CE or TiLP
2. Plug your calculator into your computer
3. Download the Latest Release of SOLVERCE.8xp
4. Send the file over to the calculator through the program.

Congratulation! The program is now on your calculator!

## HOW TO USE THE PROGRAM
On you TI 84 Calculator:
1. Press the "prgm" button inbetween the stat and cosine buttons
2. Select SOLVERCE with arrow keys and "enter"
3. Press enter to run the program

## Common Errors:
This program only works on the TI 84 Plus CE Version, not the TI 84 Plus due to its different coding style.
